# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## setup-first-run

Το περιβάλλον του lab «Κάνε ένα σιωπηλό script να τυπώσει», ανάμεσα στα μαθήματα
του κεφαλαίου `setup`. Περιέχει ένα `delivery.py` που τρέχει χωρίς να τυπώνει
τίποτα, και ένα `checks_first_run.py` που κρίνει τη δουλειά σου.

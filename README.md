# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## code-organization-meter-record

Το περιβάλλον του lab «Ένωσε τέσσερις παράλληλες λίστες σε μία class», ανάμεσα
στα μαθήματα του κεφαλαίου `code-organization`. Το `metriseis.py` κρατάει τις
μετρήσεις ρεύματος σε τέσσερις λίστες, μία ανά στήλη: η στήλη `kwh` είναι
αποθηκευμένο παράγωγο και έμεινε πίσω μετά τη διόρθωση μιας ένδειξης, ενώ η
τέταρτη μέτρηση δεν μπήκε ποτέ σε αυτήν, οπότε το `zip` τη ρίχνει σιωπηλά έξω
από την αναφορά. Το `checks_metriseis.py` συγκρίνει ολόκληρη την έξοδο με την
αναμενόμενη και δοκιμάζει τη `Reading` με δικές του τιμές.

```bash
python3 metriseis.py          # η αναφορά, όπως είναι τώρα
python3 checks_metriseis.py   # οι έλεγχοι, ξεκινάς από 0/5
```

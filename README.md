# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## data-structures-signups

Το περιβάλλον του lab «Απάντησε τρεις ερωτήσεις με τρεις δομές», ανάμεσα στα
μαθήματα του κεφαλαίου `data-structures`. Περιέχει ένα `signups.py` με τις
δηλώσεις ενός σχολείου για δύο δράσεις. Τρεις ερωτήσεις πάνω στα ίδια δεδομένα,
και καμία δεν απαντιέται σωστά: η σειρά προτεραιότητας της εκδρομής μαζεύεται σε
set και βγαίνει ανακατεμένη σε κάθε τρέξιμο, τα ονόματα βγαίνουν από το μητρώο με
τη θέση αντί για τον ΑΜ, και το «πόσοι διαφορετικοί μαθητές» μετράει γραμμές
δηλώσεων αντί για μαθητές.

Το `checks_signups.py` καλεί τις τρεις συναρτήσεις με δικά του δεδομένα και μετά
τρέχει το `signups.py` τρεις φορές, για να δει αν η έξοδος είναι και σωστή και
σταθερή.

```bash
python3 signups.py
python3 checks_signups.py
```

# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## code-organization-tuition

Το περιβάλλον του lab «Αντικατάστησε μια ιεραρχία classes με δεδομένα», ανάμεσα
στα μαθήματα του κεφαλαίου `code-organization`. Το `didaktra.py` υπολογίζει τα
μηνιαία δίδακτρα ενός φροντιστηρίου με έξι classes: κάθε συνδυασμός έκπτωσης και
λεωφορείου έχει τη δική του, δύο συνδυασμοί δεν έχουν γραφτεί ακόμα, και η
`FeeFormatter` φτιάχνεται από την αρχή μέσα στο loop της εκτύπωσης. Ο κώδικας
δουλεύει σωστά, οπότε η έξοδος πρέπει να μείνει ίδια χαρακτήρα προς χαρακτήρα.
Το `checks_didaktra.py` συγκρίνει ολόκληρη την έξοδο με την αναμενόμενη, μετράει
τις classes του αρχείου με `ast` και δοκιμάζει τη `Student` και στους δύο
συνδυασμούς που έλειπαν.

```bash
python3 didaktra.py          # η κατάσταση διδάκτρων, όπως είναι τώρα
python3 checks_didaktra.py   # οι έλεγχοι, ξεκινάς από 1/5
```

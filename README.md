# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## code-organization-library

Το περιβάλλον του lab «Βάλε τον κανόνα μέσα στη βιβλιοθήκη», ανάμεσα στα
μαθήματα του κεφαλαίου `code-organization`. Το `vivliothiki.py` κρατάει τα
διαθέσιμα αντίτυπα μιας σχολικής βιβλιοθήκης σε μια λίστα μέσα στη `Library`,
και κάθε σημείο του αρχείου την ψάχνει και τη γράφει μόνο του. Ο έλεγχος «φτάνουν
τα αντίτυπα;» υπάρχει στον έναν δανεισμό και λείπει από τον άλλον, οπότε ένας
τίτλος βγαίνει με μείον ένα αντίτυπο. Το `checks_vivliothiki.py` συγκρίνει
ολόκληρη την έξοδο με την αναμενόμενη, δοκιμάζει τη `Library` με δικά του
δεδομένα και διαβάζει το ίδιο το αρχείο με `ast` για να δει αν κάποιος από έξω
αγγίζει ακόμα τα εσωτερικά της.

```bash
python3 vivliothiki.py          # η κίνηση της ημέρας, όπως είναι τώρα
python3 checks_vivliothiki.py   # οι έλεγχοι, ξεκινάς από 0/4
```

# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## functions-inspection

Το περιβάλλον του lab «Σταμάτα τη συνάρτηση να θυμάται», ανάμεσα στα μαθήματα
του κεφαλαίου `functions`. Περιέχει ένα `inspection.py` που περνάει τα οχήματα
ενός ΚΤΕΟ: η `defects` έχει προεπιλογή `[]` και κάθε όχημα κληρονομεί τα
ελαττώματα του προηγούμενου, ενώ η ειδοποίηση φεύγει με τη λέξη `None` στη θέση
του ονόματος, επειδή ο καλών αγνόησε το `-> str | None` της `owner_of`. Το
`checks_inspection.py` καλεί την `defects` δύο φορές μέσα στην ίδια εκτέλεση, γι'
αυτό μια διόρθωση που περνάει άδεια λίστα σε κάθε κλήση δεν αρκεί.

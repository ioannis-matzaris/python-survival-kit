# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε κεφάλαιο έχει το δικό του branch, με το όνομα του κεφαλαίου. Δεν ανοίγεις
αυτό το repo με το χέρι: το lab κάθε κεφαλαίου έχει ένα κουμπί που σου φτιάχνει
ένα Codespace στο σωστό branch, με το περιβάλλον ήδη στημένο.

## data-structures

Το lab του έκτου κεφαλαίου. Ένα `analyze.py` χωρίς κανένα bug, που κάνει πάνω από
δέκα δευτερόλεπτα σε ένα αρχείο 50.000 γραμμών επειδή ψάχνει έναν κατάλογο
4.000 προϊόντων μέσα σε loop. Πρέπει να αποκτήσει πέντε συναρτήσεις με σωστές
δομές και να τελειώνει σε λιγότερο από 5 δευτερόλεπτα.

Τα δεδομένα δεν είναι στο git: το `sales.txt` πιάνει σχεδόν 3 MB. Τα φτιάχνει το
`make_data.py`, ντετερμινιστικά, με σταθερό seed.

```bash
python3 make_data.py
python3 checks.py
```

Το `checks.py` είναι ο μόνος βαθμολογητής, με 9 ελέγχους. Οι δύο τελευταίοι
είναι όρια χρόνου.

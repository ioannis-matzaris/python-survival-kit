# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε κεφάλαιο έχει το δικό του branch, με το όνομα του κεφαλαίου. Εκεί ζει ο
κώδικας του lab: τα αρχεία που θα διορθώσεις, το περιβάλλον έτοιμο στημένο, και
ένα `checks.py` που κρίνει τη δουλειά σου.

Αυτό το branch είναι σκέτο επίτηδες. Δεν χρειάζεται να ανοίξεις το repo με το
χέρι: κάθε lab μέσα στο course έχει ένα κουμπί που σου φτιάχνει ένα Codespace
απευθείας στο σωστό branch.

## Τα branches

- `setup` - το πρώτο lab: στήσιμο του περιβάλλοντος και το πρώτο script.

# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## testing-false-green

Το περιβάλλον του lab «Διόρθωσε τρία tests που δεν ελέγχουν τίποτα», ανάμεσα στα
μαθήματα του κεφαλαίου `testing`. Το `timologio.py` βγάζει το τελικό ποσό ενός
τιμολογίου, με έκπτωση στην καθαρή αξία και ΦΠΑ από πάνω. Το `test_timologio.py`
έχει τρία tests, και τα τρία περνάνε, και κανένα τους δεν θα κοκκίνιζε αν το ποσό
έβγαινε λάθος.

Το pytest εγκαθίσταται μόνο του όταν φτιάχνεται το Codespace. Μετά από αυτό δεν
χρειάζεται internet, ούτε το lab ούτε οι έλεγχοι.

Το `checks_timologio.py` δεν κοιτάει μόνο αν τα tests σου περνάνε. Τα τρέχει και
πάνω σε μια υλοποίηση που φορολογεί την αρχική αξία αντί για την τιμή μετά την
έκπτωση, και περιμένει να κοκκινίσουν.

```bash
python3 -m pytest            # τα tests, όπως είναι τώρα
python3 checks_timologio.py  # οι έλεγχοι, ξεκινάς από 0/4
```

# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## values-and-types-customer-card

Το περιβάλλον του lab «Διόρθωσε μια καρτέλα πελάτη με ελληνικά», ανάμεσα στα
μαθήματα του κεφαλαίου `values-and-types`. Περιέχει ένα `card.py` με τρία
προβλήματα γύρω από ελληνικό κείμενο και το `None`: μια μέθοδο πάνω σε τιμή που
δεν υπάρχει, ένα μήκος μετρημένο σε χαρακτήρες εκεί που ο πάροχος μετράει bytes,
και δύο ονόματα που φαίνονται ίδια χωρίς να είναι. Το `checks_card.py` κρίνει τη
δουλειά σου.

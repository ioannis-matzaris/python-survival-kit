# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## io-and-formats-history

Το περιβάλλον του lab «Σώσε το ιστορικό που σβήνεται κάθε μέρα», ανάμεσα στα
μαθήματα του κεφαλαίου `io-and-formats`.

Το `meters.py` παίρνει τις μετρήσεις ρεύματος της ημέρας από το `metriseis.txt`
και τις καταχωρεί στο `istoriko.txt`. Τρέχει καθαρά και κάνει δύο ζημιές: ανοίγει
το ιστορικό με `"w"`, οπότε οι προηγούμενες μέρες σβήνονται, και το ξαναδιαβάζει
όσο η εγγραφή είναι ακόμα ανοιχτή, οπότε τυπώνει «Γραμμές στο ιστορικό: 0».

Και τα τρία `open` του αρχείου είναι χωρίς `close` και χωρίς `with`. Η διόρθωση
είναι τρία διαδοχικά `with`, με το δεύτερο σε λειτουργία `"a"`.

Το `istoriko.txt` είναι στο git, οπότε επαναφέρεται όσες φορές χρειαστεί:

```bash
git checkout istoriko.txt
```

Το `checks_meters.py` δεν αγγίζει το `istoriko.txt` του lab. Αντιγράφει το
`meters.py` σε προσωρινό φάκελο με δικά του δεδομένα, το τρέχει δύο φορές και
ελέγχει ότι η δεύτερη εκτέλεση προσθέτει αντί να αντικαθιστά.

```bash
python3 meters.py
python3 checks_meters.py
```

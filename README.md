# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## values-and-types-order-input

Το περιβάλλον του lab «Κάνε μια παραγγελία να βγάζει σωστά νούμερα», ανάμεσα στα
μαθήματα του κεφαλαίου `values-and-types`. Περιέχει ένα `order.py` που διαβάζει
τρεις τιμές από την είσοδο και τις χρησιμοποιεί ως έχουν: πολλαπλασιάζει κείμενο
αντί για αριθμό, δέχεται το «ΟΧΙ» ως ναι, και μολύνει τις πάγιες χρεώσεις της
επόμενης παραγγελίας. Το `checks_order.py` το τρέχει με δύο διαφορετικά input.

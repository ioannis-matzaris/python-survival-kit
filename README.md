# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## testing-offers

Το περιβάλλον του lab «Μάζεψε το στήσιμο και κράτα όσα tests αξίζουν», ανάμεσα στα
μαθήματα του κεφαλαίου `testing`. Το `prosfores.py` κρατάει τις προσφορές πέντε
καταστημάτων για ένα προϊόν και βρίσκει τη φθηνότερη. Το `test_prosfores.py` έχει
πέντε tests που ξαναγράφουν τα ίδια δεδομένα πέντε φορές, και τα τέσσερα από αυτά
ελέγχουν τύπους αντί για κανόνες.

Το pytest εγκαθίσταται μόνο του όταν φτιάχνεται το Codespace. Μετά από αυτό δεν
χρειάζεται internet, ούτε το lab ούτε οι έλεγχοι.

Το `checks_prosfores.py` τρέχει το suite σου και πάνω σε δύο χαλασμένες εκδοχές του
`prosfores.py`, μία που αγνοεί τα μεταφορικά και μία που δεν αποθηκεύει τη
διαθεσιμότητα, και περιμένει να κοκκινίσει και στις δύο.

```bash
python3 -m pytest            # τα tests, όπως είναι τώρα
python3 checks_prosfores.py  # οι έλεγχοι, ξεκινάς από 0/5
```

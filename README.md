# python-survival-kit

Τα lab environments του course «Python Survival Kit».

Κάθε lab έχει το δικό του branch. Δεν ανοίγεις αυτό το repo με το χέρι: κάθε lab
έχει ένα κουμπί που σου φτιάχνει ένα Codespace στο σωστό branch, με το περιβάλλον
ήδη στημένο.

## testing-reminders

Το περιβάλλον του lab «Σταμάτα τα tests που στέλνουν αληθινά SMS», ανάμεσα στα
μαθήματα του κεφαλαίου `testing`. Το `ypenthymisi.py` στέλνει τις υπενθυμίσεις του
λογιστηρίου για τα ληξιπρόθεσμα τιμολόγια. Το `send_sms` είναι η μόνη συνάρτηση που
μιλάει με τον έξω κόσμο: εδώ γράφει μια γραμμή στο `apestalmena.log` αντί να καλέσει
τον πάροχο, ώστε να φαίνεται τι θα είχε φύγει και με τι χρέωση.

Το `test_ypenthymisi.py` έχει τρία tests που περνάνε, εκτελούν κάθε γραμμή του
module και δεν αποδεικνύουν τίποτα. Τρέξε τα μία φορά και μετά διάβασε το
`apestalmena.log`.

Το pytest εγκαθίσταται μόνο του όταν φτιάχνεται το Codespace. Μετά από αυτό δεν
χρειάζεται internet, ούτε το lab ούτε οι έλεγχοι.

Το `checks_ypenthymisi.py` τρέχει το suite σου σε προσωρινό φάκελο και κοιτάει αν
έγραψε γραμμή στο log, και το ξανατρέχει πάνω σε δύο χαλασμένες εκδοχές του
`ypenthymisi.py` περιμένοντας να κοκκινίσει.

```bash
python3 -m pytest              # τα tests, όπως είναι τώρα
cat apestalmena.log            # τι «στάλθηκε» όσο έτρεχαν
python3 checks_ypenthymisi.py  # οι έλεγχοι, ξεκινάς από 0/5
```
